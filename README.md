# Python Module 00

My first Python project, completed as part of my learning journey at 42.

## About

This repository contains the exercises from Python Module 00. The module introduces fundamental programming concepts through a collection of garden-themed exercises.

## Exercises

| Exercise | File | Description |
| --- | --- | --- |
| ex0 | `ft_hello_garden.py` | Prints a welcome message. |
| ex1 | `ft_garden_name.py` | Reads and displays a garden name. |
| ex2 | `ft_plot_area.py` | Calculates the area of a garden plot. |
| ex3 | `ft_harvest_total.py` | Calculates the total harvest over three days. |
| ex4 | `ft_plant_age.py` | Checks whether a plant is ready to harvest. |
| ex5 | `ft_water_reminder.py` | Determines whether the plants need watering. |
| ex6 | `ft_count_harvest_iterative.py` | Counts the days until harvest using a loop. |
| ex6 | `ft_count_harvest_recursive.py` | Counts the days until harvest using recursion. |
| ex7 | `ft_seed_inventory.py` | Displays seed inventory information for different units. |

## Concepts Practiced

- User input and formatted output

- Conditional statements
- Loops and recursion
- Function parameters and type hints
